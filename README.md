# Multiple Disease Prediction using Machine Learning

## Project Overview

This project predicts multiple diseases based on patient symptoms using Machine Learning classification algorithms. The objective is to compare different supervised learning models and identify the one that provides the best prediction performance.

The project uses a publicly available dataset containing various symptoms as input features and disease names as the target variable.


## Objective

- Predict diseases from patient symptoms.
- use multiple machine learning algorithms.
- Evaluate each model using classification metrics.

## Dataset

Dataset Source:
https://github.com/YBIFoundation/Dataset/raw/main/MultipleDiseasePrediction.csv

Target Variable:
- Prognosis (Disease Name)

Input Features:
- Various symptoms represented as binary values (0 = No, 1 = Yes)

## Technologies Used

- Python
- Pandas
- Scikit-learn
- Google Colab
  

## Machine Learning Models

The following classification algorithms were implemented:

- Logistic Regression
- K-Nearest Neighbors (KNN)
- Decision Tree Classifier
- Random Forest Classifier
  

## Project Workflow

1. Import required libraries
2. Load the dataset
3. Explore the data
4. Separate features and target
5. Split data into training and testing sets
6. Train multiple machine learning models
7. Make predictions
8. Evaluate model performance using classification reports


## Evaluation Metric

The models were evaluated using:

- Precision
- Recall
- F1-Score
- Accuracy (through Classification Report)
